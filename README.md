# 🤖 AI Resume Builder

AI Resume Builder is a web application that helps users create professional resumes quickly using artificial intelligence. The platform allows users to input their personal details, skills, education, and work experience, and automatically generates a structured and professional resume.

The goal of this project is to simplify resume creation by combining modern web technologies with AI-powered content generation.

# 📌 Project Overview

Creating a professional resume can be time-consuming and difficult for many job seekers. AI Resume Builder solves this problem by providing an intuitive platform where users can easily enter their information and generate a polished resume.

The application focuses on:

- Easy resume creation
- Structured resume formatting
- AI-assisted content suggestions
- User-friendly interface
- Quick generation of professional resumes

# 🚀 Features

- AI-powered resume content generation  
- Simple form-based resume creation  
- Professional resume templates  
- Real-time preview of resume content  
- Download or export resume  
- Clean and responsive user interface

# ⚙️ How It Works

1. The user enters personal details such as name, education, experience, and skills.
2. The system processes the information using AI-based suggestions.
3. The application formats the data into a professional resume structure.
4. The user can preview and download the generated resume.

# 📦 Installation & Setup

1. Clone the repository

```
git clone https://github.com/PoorvaJawale/AI-resume-builder.git
cd AI-resume-builder
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the application

```
python app.py
```

4. Open the application in your browser.
